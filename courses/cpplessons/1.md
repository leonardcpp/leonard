# Введение в C++. Структура программы. Переменные и простейшие типы данных.

Программа - это набор инструкций, которые компьютер выполняет по порядку.  
C++ - **компилируемый** язык. Это значит, что ты пишешь текст (исходный код), а специальная программа-компилятор превращает его в машинный код, который понимает процессор.

В C++ выполнение любой программы начинается с функции `main()`. Пока просто запомни: **без `main` программа не запустится**. Весь основной код должен находиться в теле этой функции, так как она является точкой входа в программу.

---
## Структура программы

Начальная структура любой программы выглядит так:
```c++
#include <iostream>

int main() {
  return 0;
}
```
Разберём по частям.

`#include <iostream>` - это команда препроцессору, так называемая **препроцессорная директива**. Она подключает стандартную библиотеку `iostream`, которая нужна для вывода текста на экран (`std::cout`) и ввода с клавиатуры (`std::cin`).

```c++
int main() {
  return 0;
}
```
Это функция `main()`. 
- `int` перед `main` означает, что функция возвращает целое число. В будущем, когда ты будешь писать свои функции, они будут возвращать самые разные типы.
    
- `return 0;` - код успешного завершения. Если вернуть не 0, операционная система поймёт, что была ошибка. Просто запомни, что эта строка должна быть в конце тела функции `main()`.
    
- Фигурные скобки `{ }` ограничивают **тело функции** - то, что выполняется.

### Инструкции

В конце каждой **инструкции** в C++ должна стоять `;`. Пропущенная `;` - одна из самых частых ошибок новичков.
```c++
int x = 5    // ОШИБКА!

int x = 5;   // Так правильно.
```

### Комментарии

В коде можно добавлять комментарии. Они нужны только для того, чтобы оставлять заметки себе или другим программистам - компилятор их игнорирует.
```c++
// Однострочный комментарий ставится с помощью 2-х слэшей вначале

/*
Многострочный
комментарий
ставится
вот так
*/
```

## Переменные

**Переменная** - это именованная область в памяти, в которой хранится значение.  
Представь коробку с наклейкой: на наклейке написано имя, внутри лежит значение. Тип переменной определяет, что можно положить в коробку (число, текст, true/false) и сколько места она займёт.

### Объявление, присваивание и инициализация
```c++
int x;             // объявление 
x = 5;             // присваивание

int variable = 42; // инициализация
```

- **Объявление** - создаём переменную нужного типа с нужным названием. Важно понимать, что память под эту переменную выделяется даже если она не хранит в себе никакого значения.
- **Присваивание** - изменение значения существующей переменной.
- **Инициализация** - установка начального значения переменной *в момент её объявления*.

Инициализация переменной более эффективна, чем создание пустой переменной с последующим присвоением значения.

### Правила именования переменных

- Имя может состоять из букв, цифр и `_`.
- Нельзя начинать с цифры.
- Нельзя использовать зарезервированные слова (`int`, `float`, `return` и т.д.).
- Регистр важен: `age` и `Age` — разные переменные.
- Хороший стиль: осмысленные имена. `playerHealth` лучше, чем `ph`.

### Константы

Если значение переменной не должно меняться, следует сделать её **константой**. Для этого нужно написать перед типом слово `const`.
```c++
const float PI = 3.1415f;

PI = 3.14; // ВЫЗОВЕТ ОШИБКУ! Значение константы изменить нельзя! 
```

##### Зачем использовать константы?

- Для безопасности кода. Ты или другой программист, который будет работать с твоим кодом,  не сможете изменить значение, которое должно оставаться неизменным.
- Компилятор C++ гораздо эффективнее работает с данными, которые гарантированно не изменятся. Зная, что значение постоянно, компилятор может подставить его напрямую в ассемблерные инструкции (вместо лишнего обращения к оперативной памяти).

А ещё в практически в любом языке программирования принято писать название констант капсом.

## Простейшие типы данных

C++ - *строго типизированный язык*. Это значит, что у каждой переменной есть тип, и он определяет:
- Какие значения можно хранить
- Сколько памяти занимает переменная
- Какие операции допустимы

### Целочисленные типы

| **Тип**     | **Занимаемая память**                                                                  | **Диапазон**                                                                      |
| ----------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `short`     | 2 байта                                                                                | от -32 768 до 32 767                                                              |
| `int`       | 4 байта                                                                                | от -2 млрд до 2 млрд                                                              |
| `long`      | 4 байта (на 64-битных системах Windows) / 8 байт (на 64-битных системах Linux и macOS) | от -2 млрд до 2 млрд / от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 808 |
| `long long` | 8 байт                                                                                 | от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 808                        |

Также стоит упомянуть про модификатор `unsigned`. Его следует использовать, если в переменной хранятся только положительные значения, так как освободившееся от отрицательных чисел место тратится на то, чтобы расширить верхнюю границу.

*Пример:*
Каждому игровому объекту на сервере присваивается уникальный id.  Он физически не может быть отрицательным. Использование `unsigned int` не просто поможет избежать ошибки с отрицательными id, но и расширит верхнюю границу с 2млрд до 4млрд. Это гарантирует, что на сервере не кончатся свободные номера для новых сущностей.
```c++
int id;          // Диапазон от -2 млрд до 2 млрд

unsigned int id; // Диапазон от 0 до 4млрд
```

### Дробные типы

| **Тип**       | **Размер**                              | **Точность**             |
| ------------- | --------------------------------------- | ------------------------ |
| `float`       | 4 байта                                 | до 7 знаков после точки  |
| `double`      | 8 байт                                  | до 16 знаков после точки |
| `long double` | 8/12/16 байт (в зависимости от системы) | до 32 знаков после точки |

По умолчанию в C++ любое дробное число воспринимается компилятором как тип `double`, даже если был явно указан тип `float`. 
Если ты напишешь:
```c++
float pi = 3.14;
```
Произойдет следующее: компилятор создаст в памяти 8-байтовое число `double`, а затем попытается принудительно обрезать его до 4-байтового `float`. Это приводит к лишней работе процессора и потенциальной потере точности.
Поэтому для экономии ресурсов и чистоты кода для любого `float` значения нужно ставить суффикс `f`:
```c++
float pi = 3.14f; // Идеально!
```

*Также запомни, что с дробными типами не получится использовать модификатор `unsigned`.*
### Логический тип

Логический тип `bool` может хранить только два значения: `true` или `false` (в памяти они хранятся как `1` и `0` соответственно). Размер составляет 1 байт.

```c++
bool isAlive = true;
bool hasAllAchievments = false;
```

### Символьный тип

Символьный тип `char` хранит один символ в одинарных кавычках. Для более широких кодировок существуют дополнительные типы:
- **wchar_t** (Unicode)
- **char16_t** (UTF-16)
- **char32_t** (UTF-32)

```c++
char weaponTier = 'S';
char armorTier = 'B';
```

### Строки

По умолчанию строчный тип `string` не доступен. Нужно подключить **препроцессорную директиву `#include <string>`**.
```c++
#include <string>

int main() {
  setlocale(LC_ALL, "Russian"); // Задаём локализацию для корректного отображения русского языка

  std::string name = "Леонард";
  
  return 0;
}
```

### Функция `sizeof()`

Функция `sizeof()` позволяет узнать размер типа в байтах:
```c++
sizeof(int)  // 4
sizeof(bool) // 1
```

## Ввод и вывод данных

В C++ ввод и вывод данных в консоль реализуется через управление потоками. Мы не будем в это углубляться, а просто рассмотрим самую базу, которой хватит для примитивных тестов и логирования.
Как уже говорилось ранее, для использования функций ввода и вывода данных необходимо подключить **препроцессорную директиву `#include <iostream>`**. 
### Вывод

Для вывода данных нам нужно как бы "втолкнуть" их в выходной поток.
```c++
#include <iostream>

int main() {
  int number = 67;
  std::cout << "Газан - " << number << std::endl;
  
  return 0;
}
```

- `std::cout` - это наш выходной поток
- `<<` - это оператор вставки данных в выходной поток
- `std::endl` - это перенос строки (необязателен)

Результат такого кода в консоли будет таким:
```
Газан - 67
```

### Ввод

Для ввода данных нам наоборот нужно внести их во входной поток.
```c++
#include <iostream>

int main() {
  int age;
  
  std::cout << "Введите возраст: ";
  std::cin >> age;
  
  return 0;
}
```

- `std::cin` - входной поток
- `>>` - оператор вставки данных во входной поток

`std::cin >> age` буквально означает, что данные, которые поступят на вход должны быть записаны в переменную `age`.

### Пространства имён

В примере мы писали `std::cout`. `std` - это пространство имён стандартной библиотеки. Чтобы не писать `std::` каждый раз, можно добавить:
```c++
using namespace std;
```
Тогда `cout`, `cin`, `endl`, `string` и другие можно писать без `std::`. Но в больших проектах (и в Unreal Engine) лучше использовать `std::` явно, чтобы избежать конфликтов имён.

Пример с `using namespace std`:
```c++
#include <iostream>
using namespace std;

int main()
{
    cout << "Привет!" << endl;
    return 0;
}
```
