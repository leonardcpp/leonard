# Циклы

## Введение: что такое циклы и зачем они нужны

До этого момента наши программы выполнялись **линейно**: одна инструкция за другой, сверху вниз. Но представь, что тебе нужно:

- вывести числа от 1 до 100;
- посчитать сумму всех чисел от 1 до `N`;
- заспавнить 20 врагов в ряд;
- спрашивать пароль, пока пользователь не введёт правильный;
- каждый кадр двигать персонажа.

Писать 100 строк `std::cout` - глупо. А «спрашивать пароль, пока не введут правильный» вообще невозможно записать линейно - мы не знаем заранее, сколько попыток понадобится.

**Цикл** - это конструкция, которая **повторяет блок кода**, пока выполняется условие.

**Аналогия:** цикл - это как «повторяй, пока не сделаешь». Как в жизни: «Пока не выучу стих - не пойду гулять», «Помешивай суп, пока не закипит», «Отожмись 10 раз». У каждого такого действия есть **условие остановки**.

В C++ есть три вида циклов: `while`, `do-while`, `for`. Они похожи, но у каждого своя ниша. Разберём каждый.

---

## Цикл `while`

### Синтаксис

```cpp
while (условие) {
    // тело цикла — выполняется, пока условие true
}
```

Как работает:

1. Проверяется условие.
2. Если `true` - выполняется тело.
3. Снова проверяется условие.
4. Если `true` - тело снова выполняется.
5. …и так до тех пор, пока условие не станет `false`.

**Важно:** если условие сразу `false` - тело **не выполнится ни разу**.

### Простой пример

```cpp
#include <iostream>

int main() {
    int health = 100;
    
    while (health > 0) {
        std::cout << "HP: " << health << std::endl;
        health -= 20; // отнимаем 20 HP
    }
    
    std::cout << "Персонаж мёртв" << std::endl;
    return 0;
}
```

**Что происходит:**

1. `health = 100`. Проверка `100 > 0` → `true`. Печатаем 100, `health` становится 80.
2. Проверка `80 > 0` → `true`. Печатаем 80, `health` = 60.
3. … и так до `health = 0`.
4. Проверка `0 > 0` → `false`. Цикл завершён. Печатаем «Персонаж мёртв».

**Ключевой момент:** внутри тела мы **меняем** `health`. Если бы не меняли - условие всегда было бы `true`, и цикл крутился бы вечно.

### Когда использовать `while`

Когда **заранее неизвестно**, сколько раз нужно повторить:

- «пока игрок жив»;
- «пока пользователь не введёт правильный пароль»;
- «пока не конец файла».

## 3. Цикл `do-while` - «сделай, потом проверь»

### Синтаксис

```cpp
do {
  // тело цикла
} while (условие);
```

Обрати внимание: **`while` стоит в конце**, и после него обязательна `;`.

Как работает:

1. Выполняется тело.
2. Проверяется условие.
3. Если `true` - тело повторяется.
4. Если `false` - цикл завершён.

**Ключевое отличие от `while`:** тело выполняется **хотя бы один раз**, потому что проверка происходит **после** него.

### Аналогия

**«Сначала попробуй суп, потом реши, добавлять ли соль».**  
Ты не можешь проверить, достаточно ли соли, не попробовав. Сначала действие (попробовать), потом проверка (посолить ещё?).

### Простой пример

```cpp
#include <iostream>

int main() {
    int number;
    
    do {
        std::cout << "Введите число от 1 до 10: ";
        std::cin >> number;
    } while (number < 1 || number > 10);
    std::cout << "Спасибо! Вы ввели " << number << std::endl;
    return 0;
}
```


**Что происходит:**

1. Тело выполняется: запрос ввода.
2. Проверка: если число меньше 1 **или** больше 10 - повторяем.
3. Как только введено корректное число - выходим.

Даже если пользователь сразу введёт `5` - запрос всё равно будет **один раз**. Это и есть смысл `do-while`.

### Когда использовать `do-while`

Когда действие **должно выполниться хотя бы один раз**:

- запрос ввода с валидацией;
- меню «Ещё раз? (y/n)»;
- «сначала покажи результат, потом спроси, продолжать ли».

## 4. Цикл `for` - «повтори N раз»

### Синтаксис

```cpp
for (инициализация; условие; шаг) {
    // тело цикла
}
```

Три части через `;`:

- **инициализация** - выполняется один раз перед циклом (обычно создаётся счётчик `int i = 0`);
- **условие** - проверяется перед каждой итерацией (пока `true` - тело выполняется);
- **шаг** - выполняется после каждой итерации (обычно `++i`).

### Аналогия

 **«Список дел на день»**: у тебя есть список (условие), ты идёшь по пунктам (шаг), и после каждого пункта зачёркиваешь его. Когда список закончился - цикл завершён.

### Простой пример

```cpp
#include <iostream>

int main() {
    for (int i = 1; i <= 5; ++i) {
        std::cout << "Враг номер " << i << " заспавнен" << std::endl;
    }
    
    return 0;
}
```

**Что происходит:**

1. `int i = 1` - создали счётчик.
2. Проверка `1 <= 5` → `true`. Печатаем «Враг номер 1 заспавнен».
3. `++i` → `i = 2`.
4. Проверка `2 <= 5` → `true`. Печатаем «Враг номер 2 заспавнен».
5. … и так до `i = 5`.
6. `++i` → `i = 6`. Проверка `6 <= 5` → `false`. Цикл завершён.

**Вывод:** 5 строк, от «Враг номер 1» до «Враг номер 5».

### Вариации

**Обратный отсчёт:**

```cpp
for (int i = 5; i > 0; --i) {
    std::cout << i << "..." << std::endl;
}
std::cout << "Поехали!" << std::endl;
```


**Шаг больше 1:**

```cpp
for (int i = 0; i < 10; i += 2) {
    std::cout << i << " "; // 0 2 4 6 8
}
```

### Когда использовать `for`

Когда **заранее известно количество повторений** или есть **явный счётчик**:

- перебрать числа от 1 до N;
- спавнить N врагов;
- обойти массив (позже, когда изучим массивы).

## 5. `break` и `continue` - управление циклом

Иногда нужно вмешаться в ход цикла.
### `break` - выйти из цикла немедленно

**Аналогия:** ты идёшь по коридору с комнатами. В каждой проверяешь, есть ли там нужный человек. Как только нашёл - **выходишь из коридора**, не проверяя оставшиеся комнаты.

```cpp
for (int i = 1; i <= 100; ++i) {
    if (i % 7 == 0)
    {
        std::cout << "Первое число, кратное 7: " << i << std::endl;
        break; // нашли — дальше не ищем
    }
}
```


Вывод: `Первое число, кратное 7: 7`. Как только нашли - вышли из цикла.

**Когда использовать:** нашли нужное - дальше искать бессмысленно.

### `continue` - пропустить остаток итерации

**Аналогия:** ты идёшь по списку дел. Пункт «помыть посуду» - но ты уже помыл её вчера. Ты **пропускаешь этот пункт** и переходишь к следующему. Дальнейшие дела в списке не отменяются.

```cpp
for (int i = 1; i <= 10; ++i) {
    if (i % 2 == 0) {
        continue; // пропускаем чётные
    }
    std::cout << i << " "; // напечатает 1 3 5 7 9
}
```

Для чётных чисел `continue` пропускает `std::cout` и сразу переходит к `++i`.

**Когда использовать:** нужно «отсеять» часть итераций, но не прерывать цикл.

## Вложенные циклы

Цикл внутри цикла. Внешний цикл выполняется `N` раз, и на каждой его итерации внутренний выполняется `M` раз. Итого - `N × M` итераций.

**Аналогия:** **таблица умножения**. Ты идёшь по строкам (внешний цикл), и для каждой строки проходишь по столбцам (внутренний цикл).

```cpp
for (int row = 1; row <= 3; ++row) {
    for (int col = 1; col <= 4; ++col) {
        std::cout << row << "×" << col << "=" << row * col << "  ";
    }
    std::cout << std::endl; // переход на новую строку
}
```


**Вывод:**
```
1×1=1  1×2=2  1×3=3  1×4=4
2×1=2  2×2=4  2×3=6  2×4=8
3×1=3  3×2=6  3×3=9  3×4=12
```

**Применение:** таблицы, сетки, спавн врагов в ряд, перебор двумерных данных.

**Осторожно с производительностью:** `1000 × 1000` = миллион итераций. В игровом цикле (каждый кадр) это может сильно замедлить игру.

## Бесконечные циклы

Иногда цикл получается **бесконечным** - программа зависает.

### Как получается случайно

**Забыли изменить условие:**

```cpp
int i = 0;
while (i < 10) {
    std::cout << i; // i никогда не станет 10 — вечный цикл
}
```


**Условие никогда не станет `false`:**

```cpp
int x = 5;
while (x > 0) {
    x = x + 1; // x только растёт — никогда не станет ≤ 0
}
```

### Намеренные бесконечные циклы

Иногда это нужно:

```cpp
while (true) {
    // игровой цикл
    if (shouldExit) break;
}
```

Так устроены многие движки - «крути игру, пока не скажут выйти».

**Но в UE4 так писать нельзя.** Движок **сам** крутит игровой цикл через `Tick()`. Если ты напишешь `while (true)` в `BeginPlay` или `Tick` - игра зависнет намертво.

### Как отлаживать

- Выведи счётчик итераций - растёт ли он?
- Для отладки поставь `break` после 10 итераций, чтобы увидеть, что происходит.
- В UE4 используй `UE_LOG` и `check`.

## 8. Задания

### 🟢 Простые

**1. Счёт до 10**  
С помощью `for` выведи числа от 1 до 10, каждое на новой строке.

**2. Сумма чисел**  
Запроси у пользователя число `N`. С помощью `for` посчитай сумму всех чисел от 1 до `N` и выведи результат. 

**3. Обратный отсчёт**  
С помощью `while` выведи числа от 10 до 1, затем «Поехали!».

---

### 🟡 Средние

**4. Угадай число**  
Загадай число (например, `42`). В цикле `while` запрашивай у пользователя попытки.  
Если введённое число больше загаданного - выведи «Меньше».  
Если меньше - «Больше».  
Если равно - «Угадал!» и `break`.

**5. Ввод с валидацией**  
С помощью `do-while` запрашивай у пользователя число от 1 до 100, пока не введут корректное (то есть не меньше 1 и не больше 100).  
После ввода выведи «Вы ввели: <число>».

**6. Таблица умножения**  
С помощью вложенных циклов выведи таблицу умножения от 1 до 10 (10×10).  
Формат:
```
1  2  3  4 ...
2  4  6  8 ...
3  6  9 12 ...
...
```

**7. Калькулятор в цикле**  
Напиши программу-калькулятор, которая:

- имеет отдельные функции `Add`, `Subtract`, `Multiply`, `Divide`
- в цикле `while` запрашивает у пользователя два числа и операцию (`+`, `-`, `*`, `/`);
- использует `switch` для выбора операции;
- если пользователь вводит `q` вместо операции - выходит из цикла;

Подсказка структуры:

```cpp
while (true) {
    // 1. спросить первое число (или 'q' для выхода)
    // 2. спросить операцию
    // 3. спросить второе число
    // 4. switch по операции
    // 5. вывести результат
}
```


**8. Мини-бой**  
Напиши программу, симулирующую бой между игроком и врагом.

Требования:

- У игрока и врага есть здоровье (`int playerHP = 100`, `int enemyHP = 80`).
- Напиши функцию `int CalculateDamage(int baseDamage, bool isCritical)`, которая возвращает урон: если `isCritical` - удвоенный, иначе обычный. Используй тернарный оператор `?:`.
- В цикле `while` (пока оба живы):
    - игрок атакует врага (урон 15, критический удар - каждый третий ход);
    - если враг жив - враг атакует игрока (урон 10);
    - выводить текущее HP обоих после каждого хода;
    - использовать `continue`, чтобы пропустить ход врага, если он уже мёртв (или `break` - на твой выбор).
- После цикла вывести, кто победил.

Подсказка: используй счётчик ходов `int turn = 0;` и проверку `turn % 3 == 0` для критического удара.
