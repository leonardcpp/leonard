# Функции, математические операторы и библиотека <cmath>

Функции - это, вероятно, одна из самых важных тем, которые мы будем рассматривать. В своих программах, особенно в Unreal Engine, ты будешь постоянно с ними работать. Но перед тем, как рассмотреть эту тему, давай быстро пройдёмся по математическим операторам.

---

## Математические операторы

C++ умеет выполнять арифметические действия:

|Оператор|Действие|Пример|Результат|
|---|---|---|---|
|`+`|сложение|`5 + 3`|`8`|
|`-`|вычитание|`5 - 3`|`2`|
|`*`|умножение|`5 * 3`|`15`|
|`/`|деление|`6 / 3`|`2`|
|`%`|остаток от деления|`7 % 3`|`1`|

При делении, если оба числа целые, результат в любом случае будет целым:
```c++
int x = 7 / 2;    // x = 3, а не 3.5!
```
Чтобы получить дробный результат, хотя бы один операнд должен быть `float` или `double`:
```c++
float x = 7.0f / 2;   // x = 3.5
```

Остаток от деления работает **только с целыми числами**. Одно из самых частых применений - проверка чётности числа:
```c++
number % 2 == 0;    // true - если чётное, false - если нечётное
```

## Инкремент и декремент

- `++` увеличивает число на 1
- `--` уменьшает число на 1

```c++
int number = 5;
number++;  // теперь number = 6
number--;  // а теперь снова 5
```

Важно также знать, что у инкремента и декремента есть 2 вида записи: **префиксный** и **постфиксный**. Они отличаются не только внешним видом, но и моментом возврата значения. Я не буду объяснять это на глубоком уровне, просто постарайся осмыслить следующее:
```c++
// Пример 1
int a = 5;
int b = ++a;
/* Сначала a увеличевается на 1 и становится 6, затем b присваивается значение a.
Итог: a = 6, b = 6 */

// Пример 2
int x = 5;
int y = x--;
/* Сначала y присваивается значение x, а уже после x уменьшается на 1 и становится 4.
Итог: x = 4, y = 5 */
```

## Составные операторы присваивания

Иногда нам нужно увеличить число на какое-то значение, или умножить, или поделить...
Допустим у нас есть число `num = 10` и мы хотим увеличить его на `5`. Запишем это:
```c++
int num = 10;
num = num + 5;
```
Работает отлично, но выглядит как-то не очень красиво. Хорошо, что в C++ есть сокращённая запись:
```c++
int num = 10;
num += 5;    // то же самое, что и num = num += 5;
```

И такая запись есть для каждого математического оператора:
```c++
int x = 10;
x += 5; // x = x + 5 -> 15
x -= 3; // x = x - 3 -> 12
x *= 2; // x = x * 2 -> 24
x /= 4; // x = x / 4 -> 6
x %= 4; // x = x % 4 -> 2
```

## Приоритет операторов

Как в математике: сначала умножение и деление, потом сложение и вычитание. Скобки меняют порядок.
```c++
int result = 2 + 3 * 4;    // 14
int result2 = (2 + 3) * 4; // 20
```

## Операторы сравнения

Они сравнивают два значения и возвращают `bool`: `true` или `false`.

|Оператор|Значение|Пример|Результат|
|---|---|---|---|
|`==`|равно|`5 == 5`|`true`|
|`!=`|не равно|`5 != 3`|`true`|
|`>`|больше|`5 > 3`|`true`|
|`<`|меньше|`5 < 3`|`false`|
|`>=`|больше или равно|`5 >= 5`|`true`|
|`<=`|меньше или равно|`3 <= 5`|`true`|

Как это выглядит в коде:
```c++
int num = 15;
bool isEven = (num % 2) == 0;  // false
```

**Важно:** сравнивать дробные числа через `==` и `!=` опасно, так как `float` и `double` хранят числа *приблизительно*. И получается так, что программа может вести себя не так, как нам надо:
```c++
float a = 0.3f;         // a = 0.3
float b = 0.1f + 0.2f;  // b = 0.30000001

bool result = a == b; // false!
```

## Функции

Наконец-то мы добрались до самого интересного. Давай поймём, что такое **функция** и зачем она нужна.

Представь: ты собрал *автомат с газировкой*. Ты кидаешь монету, нажимаешь кнопку - и получаешь бутылку. Причём если ты снова захочешь газировку, тебе не надо будет снова собирать автомат - только кинуть монетку.

**Функция - это такой же автомат.** Ты даёшь ей данные (аргументы), она что-то делает внутри и возвращает результат.

Зачем это нужно:

- **Не повторяться.** Если ты 10 раз считаешь урон по одной формуле - напиши функцию один раз и вызывай 10 раз.
- **Разбивать сложное на простое.** Большая задача = много маленьких функций.
- **Легче искать ошибки.** Если сломалась формула урона - ты знаешь, в какой функции искать.

В UE без функций никуда: `BeginPlay()`, `Tick()`, `TakeDamage()` - всё это функции. Ты будешь писать и свои.

Кстати, запомни, что функции объявляются **вне функции `main()`**. Объявляй их *до неё*.
## Анатомия функции

```c++
int add(int a, int b) {
  int result = a + b;
  return result;
}
```
Разберём каждую часть по отдельности.

1. **Возвращаемый тип**
Это **что функция отдаёт наружу**. Перед именем функции мы пишем тип того, что она вернёт.

- `int add(...)` — вернёт целое число.
- `float calculateSpeed(...)` — вернёт дробное число.
- `bool isAlive(...)` — вернёт `true` или `false`.
- `void sayHello(...)` — **ничего не вернёт** (об этом чуть позже).

2. **Имя**
Имя функции должно быть осмысленным. Правила именования у функций такие же, как у переменных.

3. **Параметры**
Это **что функция принимает на вход**. Параметры - это переменные, которые существуют **только внутри функции**.
Когда ты пишешь `(int a, int b)`, ты говоришь функции:

> «Чтобы заработать, тебе обязательно нужно два целых числа. Внутри я буду называть их `a` и `b`.»

Параметров может и не быть, но если они есть - без них функция не заработает (как автомат не заработает без монетки).

4. **Тело функции**
То, что происходит внутри `{ ... }`. Тут ты можешь использовать параметры, объявлять новые переменные и делать расчёты. Однако помни: переменные, которые ты объявляешь внутри функции существуют только внутри этой функции, точнее в её **области видимости (scope)**. Область видимости (не только функций, но и вообще любых объектов) обозначается как `{}`.

5. **`return`**
`return` - это **момент, когда функция заканчивается и отдаёт результат**.

## Возврат значения - самое важное

Давай разберём это максимально подробно, потому что тут новички спотыкаются.

### Что происходит при вызове
```c++
int sum = add(3, 5);
```

Пошагово:

1. Программа видит вызов `add(3, 5)`.
2. Создаётся **новая область памяти** для этой функции.
3. Внутри неё создаются переменные `a` и `b`, в них копируются значения `3` и `5`.
4. Выполняется тело: `int result = a + b;` → `result = 8`.
5. Выполняется `return result;` — функция **отдаёт** значение `8` туда, откуда её вызвали.
6. Область памяти функции **уничтожается**. Все её переменные (`a`, `b`, `result`) исчезают.
7. Значение `8` присваивается переменной `sum` в `main`.

**Ключевая мысль:** `return` - это как «выдача» из автомата. Автомат отдал бутылку и забыл про неё. Внутренние переменные функции после `return` больше не существуют.

### Что можно вернуть

Функция возвращает **одно значение**. Тип этого значения указан перед именем.

```c++
bool IsEven(int number) {
  return number % 2 == 0;
}
```

Вызов:
```c++
bool e = IsEven(10);  // true
```

### Что делает `return` с функцией

`return` **немедленно завершает функцию**. Код после него не выполнится.

```c++
int Check(int x) {
  if (x < 0) {
    return 0;  // если x отрицательный — выходим здесь
  }
  return x * 2;  // сюда попадаем, только если x >= 0
}
```

Здесь два `return`. Сработает только один - тот, до которого дойдёт выполнение.

### Можно ли игнорировать возврат?

Да. Если функция возвращает значение, но ты его не используешь - ничего страшного, оно просто выбросится.
```c++
add(3, 5); // вызов есть, результат никуда не сохраняется
```

Иногда это нормально (например, функция логирует что-то и возвращает статус), но чаще всего ты хочешь сохранить результат.

### Функция типа `void` - ничего не возвращает

Если функция не должна ничего отдавать, задай её тип `void`:

```c++
void sayHello() {
  std::cout << "Привет!" << std::endl;
}
```

У неё **нет `return` со значением**. Можно писать просто `return;` чтобы выйти досрочно, но обычно не пишут вообще.

```c++
void printHealth(int health)
{
    if (health <= 0)
    {
        std::cout << "Мёртв" << std::endl;
        return; // досрочный выход, ничего не возвращаем
    }
    std::cout << "HP: " << health << std::endl;
}
```

**Правило:** если функция что-то вычисляет и результат нужен снаружи - верни его через `return`. Если функция просто «делает действие» (печатает, двигает, проигрывает звук) - `void`.

## Параметры - что функция принимает

### Как это работает

```c++
void printSum(int a, int b) {
  std::cout << a + b << std::endl;
}

printSum(3, 5); // напечатает 8
```

При вызове:

1. Значение `3` копируется в `a`.
2. Значение `5` копируется в `b`.
3. Внутри функции ты работаешь с копиями.

**Важно:** функция получает **копии** значений. Оригиналы снаружи не меняются.

Пример:
```c++
void tryToChange(int x) {
  x = 100; // меняем копию
}
int main() {
  int number = 5;
  tryToChange(number);
  std::cout << number; // всё ещё 5! Не 100.
  return 0;
}
```

Почему? Потому что `x` внутри функции - это **отдельная переменная**, копия `number`. Изменение копии не трогает оригинал.
Это называется **передача по значению** (pass by value).

### Сколько параметров может быть?

Сколько угодно, но на практике не больше 4-5. Если больше, то возможно, ты делаешь что-то не то.

```c++
float distance(float x1, float y1, float x2, float y2) {
  float dx = x2 - x1;
  float dy = y2 - y1;
  return std::sqrt(dx * dx + dy * dy);
}
```

### Параметры со значениями по умолчанию

Можно задать значение, которое используется, если аргумент не передан:

```c++
void greet(std::string name, std::string greeting = "Привет") {
  std::cout << greeting << ", " << name << "!" << std::endl;
}
Greet("Леонтий");              // Привет, Леонтий!
Greet("Георгий", "Здарова");   // Здарова, Георгий!
```

Правило: параметры со значением по умолчанию должны идти **после** обычных.

## Область видимости
### Локальные переменные

Всё, что объявлено внутри `{ }` функции - **локальное**. Оно существует только пока функция работает.

```c++
void foo() {
  int x = 10;     // x существует только здесь
  std::cout << x;
}                 // здесь x уничтожается
int main() {
  foo();          // 10
  std::cout << x; // ОШИБКА: x здесь не существует
  
  return 0;
}
```

**Аналогия:** локальные переменные - это как вещи в номере отеля. Ты заселился, разложил вещи, выехал - вещей больше нет. Другой постоялец (другой вызов функции) получит чистый номер.

### Параметры - тоже локальные

Параметры функции - это тоже локальные переменные. Они живут только внутри функции.

```c++
int add(int a, int b) {
  // a и b - локальные, живут только здесь
  return a + b;
}
// здесь a и b уже не существуют
```

### Два вызова - две независимые копии

Очень важно понять:

```c++
int add(int a, int b) {
  return a + b;
}

int main()
{
    int x = add(3, 5);
    // создались a=3, b=5, посчиталось 8, они уничтожились
    
    int y = add(10, 20);
    // создались НОВЫЕ a=10, b=20, посчиталось 30, уничтожились
    
    return 0;
}
```

Каждый вызов - **свежие переменные**. Они не помнят значения с прошлого раза.

### Глобальные переменные

Переменные, объявленные **вне** всех функций, называются глобальными. Они живут всю программу и видны везде.

```c++
int globalCounter = 0; // глобальная (находится вне функций)

void increment() {
    globalCounter++;   // можем менять
}

int main() {
  increment();
  std::cout << globalCounter; // 1
  
  return 0;
}
```

**Но:** глобальные переменные - зло в больших проектах. Они создают путаницу: непонятно, кто и когда их меняет. Используй их только когда действительно нужно.

В UE глобальных переменных почти нет - вместо них используют поля классов (`UPROPERTY`).
### Конфликт имён

Если локальная переменная называется так же, как глобальная - локальная «перекрывает» глобальную внутри функции.

```c++
int x = 100; // глобальная

void foo()
{
    int x = 5;      // локальная, перекрывает глобальную
    std::cout << x; // 5
}
int main() {
  foo();
  std::cout << x; // 100
  
  return 0;
}
```

Это ещё одна причина избегать глобальных переменных.

## Перегрузка функций

**Перегрузка функций** - это когда в программе есть **несколько функций с одинаковым именем, но разными параметрами**.
Компилятор сам понимает, какую из них вызвать, по типу и количеству аргументов.

Пример:
```c++
#include <iostream>

int add(int a, int b) {
  return a + b;
}

float add(float a, float b) {
  return a + b;
}

std::string add(std::string a, std::string b) {
  return a + b;
}

int main() {
  std::cout << Add(3, 5) << std::endl;
  // 8 (int-версия)
  
  std::cout << Add(3.5f, 1.2f) << std::endl;
  // 4.7 (float-версия)
  
  std::cout << Add("При", "вет") << std::endl;
  // Привет (string-версия)
  
  return 0;
}
```

## Как это работает

Когда ты пишешь `add(3, 5)`, компилятор смотрит:
- сколько аргументов передано - 2;
- какого они типа - `int`, `int`;
- есть ли функция `Add` с двумя `int` - есть. Вызывает её.

Если бы ты вызвал `add(3.5f, 1.2f)` - компилятор выбрал бы `float`-версию.

## Что считается разными параметрами

Перегрузка работает, если функции отличаются **хотя бы одним** из:
1. **Типом параметров.**
```c++
void print(int x);
void print(float x);
```

2. **Количеством параметров.**
```c++
int max(int a, int b);
int max(int a, int b, int c);
```

3. **Порядком параметров.**
```c++
void set(int a, float b);
void set(float a, int b);
```

## Что НЕ считается

Перегрузка **не работает**, если функции отличаются только:
- **типом возвращаемого значения.**
```c++
int get();     // ошибка: компилятор не сможет выбрать
float get();   // ошибка
```

- **именами параметров.**
```c++
void foo(int a);
void foo(int b); // то же самое
```

## Библиотека `cmath`

В C++ есть стандартная библиотека `<cmath>`, которая содержит множество математических функций. Подключается так:
```c++
#include <cmath>
```

В отдельных случаях, если такое подключение не работает, можно попробовать добавить её так:
```c++
#include <math.h>
```

Все функции находятся в пространстве имён `std`, поэтому пишем `std::sqrt`, `std::pow` и т.д.

### Основные функции

Тут я не буду сильно заострять внимание, лишь оставлю краткую таблицу с основными функциями библиотеки.

|Функция|Что делает|Пример|
|---|---|---|
|`std::sqrt(x)`|квадратный корень|`std::sqrt(9.0)` → `3.0`|
|`std::pow(x, y)`|возведение x в степень y|`std::pow(2.0, 3.0)` → `8.0`|
|`std::abs(x)`|модуль числа|`std::abs(-5)` → `5`|
|`std::sin(x)`|синус (x в радианах)|`std::sin(M_PI/2)` → `1.0`|
|`std::cos(x)`|косинус|`std::cos(0.0)` → `1.0`|
|`std::tan(x)`|тангенс|`std::tan(M_PI/4)` → `1.0`|
|`std::asin(x)`|арксинус|`std::asin(1.0)` → `π/2`|
|`std::acos(x)`|арккосинус|`std::acos(1.0)` → `0`|
|`std::atan(x)`|арктангенс|`std::atan(1.0)` → `π/4`|
|`std::atan2(y, x)`|арктангенс y/x с учётом четверти|используется для углов|
|`std::floor(x)`|округление вниз|`std::floor(3.7)` → `3.0`|
|`std::ceil(x)`|округление вверх|`std::ceil(3.2)` → `4.0`|
|`std::round(x)`|округление до ближайшего|`std::round(3.5)` → `4.0`|
|`std::fmod(x, y)`|остаток от деления для дробных|`std::fmod(7.5, 2.0)` → `1.5`|
|`std::exp(x)`|экспонента (e^x)|`std::exp(1.0)` → `2.718...`|
|`std::log(x)`|натуральный логарифм|`std::log(M_E)` → `1.0`|
|`std::log10(x)`|десятичный логарифм|`std::log10(100.0)` → `2.0`|

## Теперь давай соберём всю информацию в один пример

Задача: написать функцию, которая считает урон с учётом брони. ^b34284
```c++
#include <iostream>

/*
Функция принимает: базовый урон, броню цели.
Возвращает: итоговый урон после уменьшения.
*/

float calculateDamage(float baseDamage, float armor = 0.0) {
  // Если броня не передаётся в функцию, то считается как 0.0
  // Защита уменьшает урон по формуле: урон / (1 + броня/100)
  float reduction = 1.0f + armor / 100.0f;
  float finalDamage = baseDamage / reduction;

  return finalDamage;
}

int main() {
  float damage = сalculateDamage(100.0f, 50.0f);
  std::cout << "Итоговый урон: " << damage << std::endl; // ~66.67

  float damage2 = CalculateDamage(50.0f);
  std::cout << "Без брони: " << damage2 << std::endl; // 50

  return 0;
}
```

Что здесь происходит:
- `baseDamage` и `armor` - **параметры**, локальные для функции.
- `reduction` и `finalDamage` - **локальные переменные**, живут только внутри.
- `return finalDamage;` - функция **отдаёт** результат в `main`.
- `damage` в `main` - **другая переменная**, она получает значение, которое вернула функция.
- После завершения `сalculateDamage` переменные `baseDamage`, `armor`, `reduction`, `finalDamage` **уничтожаются**.
