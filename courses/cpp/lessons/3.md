# Условные конструкции и логические операторы

## Зачем нужны условия

До этого момента все наши программы выполнялись **линейно**: сверху вниз, строка за строкой. Но игра - это не линейный сценарий. В ней постоянно нужно выбирать:
- Если здоровье ≤ 0 - умереть.
- Если нажата кнопка прыжка и персонаж на земле - прыгнуть.
- Если у игрока есть ключ - открыть дверь, иначе - показать «Заперто».

и так далее...

Всё это - **ветвления**. Инструмент для них - **условные конструкции**.

# Логические операторы

## Что это и зачем

Операторы сравнения (`==`, `>`, `<` и т.д.) отвечают на **один** вопрос и возвращают `bool`. Но в игре почти всегда нужно **несколько условий сразу**.
Для этого есть **логические операторы**. Они берут один или несколько `bool` и возвращают новый `bool`. Их три: `&&`, `||`, `!`.

---

## 1. `&&` - логическое И

`true`, только если **оба** операнда истинны.

| A | B | A && B |
|---|---|--------|
| true | true | **true** |
| true | false | false |
| false | true | false |
| false | false | false |

```cpp
if (health > 0 && hasKey)
{
    std::cout << "Можно открыть дверь";
}
```

**Аналогия:** два замка на двери. Открыть можно, только если открыты оба.

---

## 2. `||` - логическое ИЛИ

`true`, если **хотя бы один** операнд истинен.

| A | B | A \|\| B |
|---|---|--------|
| true | true | **true** |
| true | false | **true** |
| false | true | **true** |
| false | false | false |

```cpp
if (hasKey || doorBroken)
{
    std::cout << "Дверь открыта";
}
```

**Аналогия:** две дороги к цели. Дойти можно по любой — неважно, что вторая закрыта.

---

## 3. `!` - логическое НЕ

Инвертирует `bool`. Один операнд.

| A | !A |
|---|-----|
| true | false |
| false | true |

```cpp
if (!isGameOver)
{
    std::cout << "Игра продолжается";
}
```

**Аналогия:** выключатель. Было «вкл» - стало «выкл».

---

## Комбинирование и приоритет

```cpp
if ((health > 0 && hasKey) || isBoss) { }
```

Приоритет без скобок: `!` > `&&` > `||`.  
**Совет:** всегда ставь скобки, когда смешиваешь `&&` и `||` — иначе читается неоднозначно.

---
## Конструкция `if`

Самая базовая форма:

```cpp
if (условие)
{
    // код, который выполнится, если условие истинно
}
```

Пример:

```cpp
int health = 50;

if (health > 0)
{
    std::cout << "Персонаж жив" << std::endl;
}
```

- `health > 0` - **условие**. Оно возвращает `bool` (`true` или `false`).
- Если `true` - выполняется блок в `{ }`.
- Если `false` - блок пропускается, программа идёт дальше.

---

## `if-else`

Если нужно два варианта действий:

```cpp
if (условие)
{
    // если true
}
else
{
    // если false
}
```

Причём `else` выполняется тогда и только тогда, когда не выполняется условие `if`.

Пример:

```cpp
int health = 0;

if (health > 0)
{
    std::cout << "Живой" << std::endl;
}
else
{
    std::cout << "Мёртвый" << std::endl;
}
```

**Важно:** выполняется **только один** из блоков. Либо `if`, либо `else`.

---

## `else if` - цепочка условий

Когда вариантов больше двух:

```cpp
if (условие1)
{
    // ...
}
else if (условие2)
{
    // ...
}
else if (условие3)
{
    // ...
}
else
{
    // если ни одно не сработало
}
```

Пример - определение оценки:

```cpp
int score = 75;

if (score >= 90)
{
    std::cout << "Отлично" << std::endl;
}
else if (score >= 75)
{
    std::cout << "Хорошо" << std::endl;
}
else if (score >= 60)
{
    std::cout << "Удовлетворительно" << std::endl;
}
else
{
    std::cout << "Неудовлетворительно" << std::endl;
}
```

Проверки идут **сверху вниз**. Как только одна сработала - остальные пропускаются, даже если они тоже истинны.

**Типичная ошибка:** порядок условий.

```cpp
if (score >= 60)
{
    std::cout << "Удовлетворительно"; // сработает первым и для 95
}
else if (score >= 90)
{
    std::cout << "Отлично"; // сюда уже никогда не попадём
}
```

Всегда ставь **более строгие условия выше**, менее строгие - ниже.

---

## Вложенные `if`

Один `if` внутри другого:

```cpp
int health = 50;
bool hasKey = true;

if (health > 0)
{
    if (hasKey)
    {
        std::cout << "Открываем дверь" << std::endl;
    }
}
```

Это эквивалентно:

```cpp
if (health > 0 && hasKey)
{
    std::cout << "Открываем дверь" << std::endl;
}
```

**Когда что использовать:**
- Если условия **логически связаны** (жив И есть ключ) - используй `&&`.
- Если внутри первого `if` есть **ещё логика** помимо второго условия - вложенность оправдана.

Глубокая вложенность (3+ уровня) - плохой знак. Разбивай на функции или используй `&&`/`||`.

---

## Логические операторы в условиях

Здесь они раскрываются во всей красе. Вспомним:
- `&&` - И (оба истинны).
- `||` - ИЛИ (хотя бы одно истинно).
- `!` - НЕ (инверсия).

### Пример с `&&`

```cpp
int health = 50;
bool hasWeapon = true;

if (health > 0 && hasWeapon)
{
    std::cout << "Готов к бою" << std::endl;
}
```

### Пример с `||`

```cpp
bool hasKey = false;
bool doorBroken = true;

if (hasKey || doorBroken)
{
    std::cout << "Дверь открыта" << std::endl;
}
```

### Пример с `!`

```cpp
bool isAlive = true;

if (!isAlive)
{
    std::cout << "Игра закончена" << std::endl;
}
```

### Комбинация

```cpp
int health = 50;
bool hasKey = true;
bool isBoss = false;

if ((health > 0 && hasKey) || isBoss)
{
    std::cout << "Проход разрешён" << std::endl;
}
```

Скобки здесь не обязательны (у `&&` приоритет выше, чем у `||`), но **ставь их всегда**, когда смешиваешь операторы. Так код читается однозначно.

## Конструкция `switch`

Когда вариантов много и все они - **сравнения с конкретными значениями**, удобнее `switch`:

```cpp
int day = 3;

switch (day)
{
    case 1:
        std::cout << "Понедельник" << std::endl;
        break;
    case 2:
        std::cout << "Вторник" << std::endl;
        break;
    case 3:
        std::cout << "Среда" << std::endl;
        break;
    default:
        std::cout << "Другой день" << std::endl;
        break;
}
```

Разбор:
- `switch (day)` - проверяем значение `day`.
- `case 1:` - если `day == 1`, выполняем этот блок.
- `break;` - **выход из `switch`**. Без него выполнение «провалится» в следующий `case`.
- `default:` - если ничего не совпало.

### Когда использовать `switch`, а когда `if`

- **`switch`** - когда сравниваешь **одну переменную** с **набором конкретных значений** (день недели, тип оружия, состояние игры).
- **`if-else`** - когда условия **разные** (диапазоны, разные переменные, логические комбинации).

`switch` работает только с целочисленными типами (`int`, `char`, `enum`) и не работает с `float`, `std::string` (в стандартном C++).

---

## 8. Тернарный оператор `? :`

Сокращённая форма `if-else`, возвращающая значение.

```cpp
условие ? значение_если_true : значение_если_false
```

Пример:

```cpp
int health = 50;
std::string status = (health > 0) ? "Живой" : "Мёртвый";
```

Эквивалент:

```cpp
std::string status;
if (health > 0)
{
    status = "Живой";
}
else
{
    status = "Мёртвый";
}
```

**Когда использовать:** для коротких присваиваний.

В UE4 тернарный оператор встречается часто:

```cpp
float Speed = bIsSprinting ? SprintSpeed : WalkSpeed;
```

---

## 9. Сложные условия - как не запутаться

Когда условий много, легко написать нечитаемую кашу. Вот приём:

### Разбивай на именованные `bool`

Плохо:

```cpp
if (health > 0 && !isStunned && (hasWeapon || isMelee) && !isDead)
```

Лучше:

```cpp
bool canAct = health > 0 && !isStunned && !isDead;
bool canAttack = canAct && (hasWeapon || isMelee);

if (canAttack)
{
    // ...
}
```

Имена `canAct`, `canAttack` объясняют смысл. Код читается как предложение.
